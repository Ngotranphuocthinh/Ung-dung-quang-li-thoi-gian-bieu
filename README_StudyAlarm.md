# Study Alarm

Ung dung nhac lich cho sinh vien (Flutter), toan bo code nam trong `lib/main.dart`.

## Chay thu (Windows)
- Bam doi `run_chrome.bat` de chay tren Chrome.
- Hoac mo may ao Android roi bam `run_emulator.bat`.

Hoac go tay trong Terminal tai thu muc nay:

    flutter create .
    flutter pub get
    flutter run -d chrome

(Neu `flutter create .` ghi de lib/main.dart thi chep lai file main.dart cua ban.)
